# targetSdk 36 (Android 16) 상향 실행 계획

> **For agentic workers:** REQUIRED SUB-SKILL: `superpowers:subagent-driven-development` (권장) 또는 `superpowers:executing-plans` 로 태스크 단위 실행. 각 단계는 체크박스(`- [ ]`)로 추적한다.

**Goal:** 체크인 키오스크 앱의 `compileSdk`/`targetSdk` 를 35 → 36 으로 올리고, Android 16 동작 변경으로 깨지는 곳이 없음을 실기기/에뮬레이터로 확인한다.

**Architecture:** 코드 변경은 사실상 없다. (1) 툴체인(Gradle/AGP)을 compileSdk 36 이 가능한 최소 버전으로 올리고, (2) SDK 숫자를 바꾸고, (3) targetSdk 36 에서만 발동하는 동작 변경(엣지투엣지 강제, predictive back 기본 활성, 큰 화면 방향 제한 무시)을 실제 기기에서 검증한다. 툴체인 변경과 SDK 변경을 별도 커밋으로 나눠 회귀 원인을 분리한다.

**Tech Stack:** Android Gradle Plugin 8.10.1, Gradle 8.11.1, Kotlin 2.1.0, Jetpack Compose, CameraX 1.4.1, ML Kit, Hilt

**Spec:** 별도 스펙 문서 없음. 근거는 Android 공식 문서 두 곳:
- AGP 8.10 호환표 (compileSdk 최대 36, Gradle 최소 8.11.1, JDK 17): https://developer.android.com/build/releases/agp-8-10-0-release-notes
- targetSdk 36 동작 변경: https://developer.android.com/about/versions/16/behavior-changes-16

## Global Constraints

- `minSdk = 26` 유지. 낮추거나 올리지 않는다.
- Kotlin `2.1.0`, KSP `2.1.0-1.0.29`, Compose BOM `2024.12.01` **버전 변경 금지**. 이번 작업 범위는 AGP/Gradle/SDK 뿐이다.
- AGP 는 정확히 `8.10.1`, Gradle 은 정확히 `8.11.1` 을 쓴다. (AGP 8.9 는 compileSdk 최대 35라 안 된다. AGP 9.x 는 Kotlin/KSP 동반 상향이 필요해 이번 범위 밖이다.)
- JDK 17 로 빌드한다. 현재 환경: Temurin 17.0.20 (확인 완료).
- Android SDK Platform 36, Build-Tools 36.0.0 은 이미 설치돼 있다 (`~/Library/Android/sdk`). 추가 설치 불필요.
- `versionCode` / `versionName` 은 Task 4 에서만 건드린다. Task 1~3 에서는 그대로 둔다.
- 이 프로젝트에는 테스트 소스셋이 아예 없다(`app/src/main` 만 존재). 새로 테스트 프레임워크를 깔지 않는다. 검증 = **빌드 성공 + 기기 스모크 테스트**.
- 커밋 메시지는 기존 컨벤션대로 `chore:` / `fix:` 접두어 + 한국어 본문.
